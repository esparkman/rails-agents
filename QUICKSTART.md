# Rails-agents harness — quickstart

Set up the harness in three steps. It works wherever you put it — pick any
directory you like; nothing here assumes a specific location.

Prerequisites: Claude Code, plus `bash`, `git`, `python3`, and `ruby`.

---

## 1. Clone the engine

Choose where the harness should live and clone it there:

```sh
# Pick any location you like:
export HARNESS_DIR="$HOME/claude-harness"

git clone https://github.com/esparkman/rails-agents.git "$HARNESS_DIR"
```

## 2. Install the global ruleset (once per machine)

The ruleset ships in the private handoff bundle (`harness-personal.tar.gz`), not
in the repo. Unpack it and copy the ruleset into your Claude Code config:

```sh
tar xzf harness-personal.tar.gz
mkdir -p "$HOME/.claude"
cp global-CLAUDE.md "$HOME/.claude/CLAUDE.md"
```

## 3. Wire each project

Run the installer against any Rails project. Re-runnable and safe:

```sh
"$HARNESS_DIR/install.sh" /path/to/your-rails-app
# wire more than one at a time:
"$HARNESS_DIR/install.sh" /path/to/app-one /path/to/app-two
```

Per project, this symlinks the agents into `.claude/agents/`, writes
`.claude/settings.json` with the SessionStart banner + Stop verification gate,
and adds the harness `.gitignore` lines. The agent symlinks are machine-local
and regenerated by the installer, so nothing carrying an absolute path is ever
committed.

---

## Confirm it worked

Open Claude Code in a wired project. You should see the init block report
`Delegation: ENFORCED` with the agent list. If your status line shows a harness
segment, it reads `[⚙ N·gate]` when healthy.

If it reports `Delegation: OFF`, or the status line shows a red `✗`, re-run:

```sh
"$HARNESS_DIR/install.sh" /path/to/your-rails-app
```

## Notes

- **Location is remembered per project.** The installer writes the hook path
  based on where you cloned the harness. If you later move the clone, re-run
  `install.sh` on each project so the path updates.
- **Restart after first install.** A running Claude Code session may not pick up
  a new `settings.json` mid-flight — restart it (or open `/config` once).
- **Requirements recap:** `bash`, `git`, `python3` (status banner), `ruby`
  (the Definition-of-Ready lint).
