# Rails-agents harness — handoff

This bundle is the whole harness: the sub-agent roster, the verification machinery,
the global ruleset, and the docs. It is self-contained and portable — nothing here
hard-codes a username or an absolute home path. Clone it anywhere and run `install.sh`.

## What's inside

| Path | What it is |
|---|---|
| `*.md` (24 files) | The agent roster — `rails-architect`, `dhh-code-reviewer`, the `rails-*` engineers, `story-writer`, plus the bundle `CLAUDE.md`/`README`. |
| `reference/hooks/verification_gate.sh` | **Stop hook** — warns (warn mode) when a code task stops without the operator-task test / full suite / code review evidenced. |
| `reference/hooks/session_start_banner.sh` | **SessionStart hook** — prints an environment-verified harness-status banner into the session's context every session. |
| `reference/story-writer/` | DoR gate (`dor_lint.rb`), input schema, requirements→test traceability (`trace_coverage.rb`). |
| `reference/tomes/tome.sh` | Book-library reader used by story-writer / architect. |
| `install.sh` | Wires the harness into a target repo (portable, idempotent). |

**Personal layer (not in this public repo):** the global ruleset (`global-CLAUDE.md`)
and the internal runbooks/specs (`docs/`) carry personal workflow and vault config, so
they are handed off privately (a `harness-personal.tar.gz`), not committed here.

## Install (recipient)

```sh
# 1. Clone the bundle wherever you like (under $HOME keeps settings.json portable).
git clone git@github.com:esparkman/rails-agents.git ~/Development/rails-agents

# 2. Drop in the global ruleset (one time per machine). Ships in the private
#    handoff tarball, not this repo — unpack it, then:
cp global-CLAUDE.md ~/.claude/CLAUDE.md

# 3. Wire each project repo. Re-runnable; never clobbers other hooks.
cd ~/Development/rails-agents
./install.sh ~/path/to/some-rails-app ~/path/to/another-app
```

`install.sh` per target: symlinks the 24 agents into `.claude/agents/`, writes
`.claude/settings.json` with the SessionStart banner + Stop gate, and appends the
harness `.gitignore` block. The agent symlinks are machine-local build output —
`.gitignore` excludes them, so they're regenerated by `install.sh`, never committed
with someone else's path.

## How you can tell it's wired

Two signals, by design:

1. **SessionStart banner (ground truth).** The hook feeds Claude an environment-verified
   status line every session (`agents: 24 -> …`, `verification gate: armed`). This is
   real, checked state — not the model's memory.
2. **The model's init block (what you see).** Per `global-CLAUDE.md`, the model emits the
   `🟢 Global CLAUDE.md loaded …` block at session start, now grounded in the banner's
   facts. This is the human-visible confirmation in the conversation.

Hook stdout is not guaranteed to print to your terminal, so the model's init block is the
signal *you* read; the SessionStart hook is what makes that block trustworthy.

## Portability notes

- The hook path in a committed `settings.json` is written `$HOME/...`-relative when the
  bundle lives under home, so it survives a clone to the same spot on another machine.
  If you clone the bundle elsewhere, re-run `install.sh` so the path matches.
- Requires: `bash`, `git`, `python3` (used only to emit the banner's JSON).
